# SCRIPTORIA
**Write Your Script.**

Independent, local-first Windows scriptwriting studio for YouTube storytellers. **Not** a video editor.

## Product direction
- Black, red, white identity distinct from NOEMA's green book-writing design.
- Organize scripts under a **channel identity** (mission, tone, audience).
- A video's **thumbnail is creative context** for understanding its topic and direction, not a thumbnail editor.
- Main output: editable script and its arguments, sections and narration.
- Sources and concept references belong to their video.
- Roadmap: AI chat beside the script with durable project memory, author-controlled changes and optional vision analysis of thumbnail.
- Separate Tauri app identity and SQLite data location: never touches NOEMA's files.

## First foundation
Channel profiles, per-channel scripts, script/idea editor with autosave, thumbnail import and preview, attached supporting materials, plus a Windows installer built by GitHub Actions. See `docs/FOUNDATION.md` for limitations and development details.

**Do not import personal source files, credentials or manuscript backups into this public GitHub repository.** Writing remains local to the installed application.
